# 確認価格帯 + Measured Move + net 2R の検証

2026-10-07。モデル `confirmation_zone_measured_net2r_v1`。結果を見る前に条件を別プロトコルとして固定し、GitHub commit `9c93cf647c7f7f08336530fffc76421bcfd0be47` へ記録した。過去期間は既に他の分析で見ており、未検証のホールドアウトとは扱わない。

## 固定した変更

既存Shadow v2の最初の確認済みセットアップを起点とする。4H構造SL、リテスト、15分足の方向とロール水準を抜けた終値を維持する。待ち価格は確認足終値で、ロール水準の確認側に置く。

両側5bpsの手数料と両側2bpsの不利なスリッページを考慮し、その待ち価格でnet 2RとなるTPを発生時点に固定する。TPが既存のMeasured Move extensionに収まらないセットアップは除外し、その後の都合のよい確認足で再開しない。SLを広げず、待機期限は既存案と同じ4本。

signal close +1msによりsignal candleを除外する。待機中は各足の開始時点までに確定したsetup、確認条件、リテスト、構造SLの有効性を確認する。ロール水準・SLを越える始値では拒否する。約定足内のTP/SL接触は順序を推測せずAMBIGUOUSとし、MFE/MAEにもその足の極値を使わない。

## 判断

**KILL_NO_LIVE_PROMOTION**。

仮想エントリー数は増えたが、両期間とも20件以上の確定結果で平均R<=0かつPF<=1。事前の停止基準に従い、この仕様の案を不採用とする。OPENが残るため、全コホートの最終利益率が確定したという結論ではない。現時点の観測済み結果を根拠に、本番昇格と新案の将来収集を停止する判断である。

条件を結果に合わせて調整せず、将来Shadow収集も起動しない。実装・プロトコル・結果は再現用に保存する。既存の固定済み週次検証、Shadow v2の結果追跡、候補履歴、ENTRY NOW、READY-only Pushは維持する。

価格位置とコストの整合を修正しても利益は改善しなかった。次の仮説を作る場合は、対象セットアップの値動き・失敗理由を先に調べ、別の条件・期間・停止基準として登録する。このモデルの勝ちやすかった部分だけを後から本番条件へ追加しない。

この研究は公開OHLCの価格接触を用いた仮想約定であり、注文執行、板・キュー・実約定、Fundingを検証したものではない。
