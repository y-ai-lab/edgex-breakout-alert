# 4Hトレンド方向の15Mレンジ端反転案

2026-10-07。独立モデル `trend_range_sweep_reclaim_net2r_v1`。[条件・期間・停止基準を結果閲覧前に固定](https://github.com/y-ai-lab/edgex-breakout-alert/commit/b4284e0a5faaa651d8e27f97b88ac46084693790)。開発期間は既閲覧の市場データで、未使用ホールドアウトでもリアルタイムShadow収集でもない。

4Hの確定足がEMA20/50トレンドを満たす方向だけを対象にする。LONGは確定15M足が直前20本のレンジ安値を厳密に下回り、その水準を上回って陽線で閉じること。SHORTは逆。4Hブレイクアウトを待つ既存戦略と異なる入り方を検証した。

この独立モデルのSLは反転足の安値・高値から0.5 ATR15のバッファを付けた構造無効化価格。既存の4H構造SLを変更しない。TPの上限は信号足を除いた事前レンジの反対端から0.25 ATR15を差し引き、信号終値の指値・片道手数料5bps・不利なスリッページ2bpsを含むnet 2Rが収まる場合だけ候補にする。SL・TPを後から調整しない。

signal close+1ms以降だけで約定と決着を評価する。指値約定足でのexit接触は順序不明としてAMBIGUOUS、後続足のTP/SL両接触もAMBIGUOUS。欠損足では追跡を停止し、SLの不利な寄り付きgapは実際の想定損失へ反映する。約定前にトレンド・足方向・凍結水準・リテスト・元SLの有効性を再確認し、4本で待機を終了する。既存検証器を純粋関数で再利用し、DB・Push・注文APIに接続しない。
